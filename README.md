# greenapi_test

Тестовое задание в GREEN-API на позицию специалиста технической поддержки 2 линии.

HTML-страница с вызовом методов GREEN-API:

- getSettings
- getStateInstance
- sendMessage
- sendFileByUrl

Ответ метода выводится в поле справа.

## Запуск

Открыть index.html в браузере, сборка и зависимости не нужны.

В поля вверху вставить apiUrl, idInstance и apiTokenInstance со страницы инстанса в [личном кабинете GREEN-API](https://console.green-api.com).

## Примечания

- По сравнению с макетом добавлено поле apiUrl. У инстансов разные хосты, а общий api.green-api.com в документации указан как временный, поэтому хост берется из личного кабинета. mediaUrl не нужен, он используется только в UploadFile и SendFileByUpload.
- Номер вводится цифрами (например 77771234567), @c.us подставляется автоматически.
- Для sendFileByUrl имя файла берется из ссылки.
- При ошибке в поле выводится код ответа и тело: 401 неверный токен, 403 apiUrl от другого инстанса, 429 слишком частые запросы, 466 закончился лимит тарифа.
